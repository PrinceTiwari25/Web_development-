# 🤖 AI Image Generator (Frontend Project)

## 📌 Project Overview

The **AI Image Generator** is a frontend-based web application that allows users to generate images from text prompts using a free AI image API.

Users can enter any prompt such as *"cyberpunk city"* or *"anime boy"* and instantly get an AI-generated image.

---

## 🚀 Features

* 🎨 Generate images from any text prompt
* ⚡ Instant results using free AI API
* 🧠 Smart prompt suggestions
* 💻 Responsive and modern UI (Glassmorphism design)
* 🔄 Multi-page navigation (Input → Result)
* 🌐 No backend required
* 🆓 No API key or billing required

---

## 🛠️ Technologies Used

* HTML5
* CSS3 (Glassmorphism UI)
* JavaScript (DOM Manipulation, LocalStorage)
* Free AI Image API (Pollinations)

---

## 📂 Project Structure

```
ai-image/
│
├── index.html        (Prompt input page)
├── result.html       (Generated image page)
├── style.css         (UI styling)
├── script.js         (Application logic)
│
└── images/           (Optional local images)
```

---

## ⚙️ How It Works

1. User enters a text prompt
2. The prompt is stored using **LocalStorage**
3. User is redirected to result page
4. The app fetches an AI-generated image using the API
5. The image is displayed instantly

---
